# Full Dashboards

> **The outcome comes first.**

Each project starts with a decision somebody needs to make.

The data model, interaction, and visual language follow from that decision.

This folder contains complete dashboard and reporting projects built across Power BI, Tableau, Python, and other tools. Each project focuses on a specific business problem, with the goal of making the analysis easier to understand and the outcome easier to act on.

## 🎯 Design Approach

Across these projects, I focus on a few principles:

### Start with the decision

A dashboard should help someone answer a question or make a decision—not simply display data.

### Make the analysis visible

Where possible, the dashboard should help users understand **why** something happened, not only **what** happened.

### Use interaction with purpose

Filters, drilldowns, custom visuals, and navigation should make exploration easier rather than add complexity.

### Treat visual design as part of the analysis

Layout, hierarchy, typography, colour, and interaction all contribute to how quickly a user can understand the information.

### Build reusable solutions

Where possible, I use reusable DAX patterns, SVGs, themes, design files, and other techniques that can be applied to future projects.
